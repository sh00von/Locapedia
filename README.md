# Locapedia

Discover Wikipedia articles about places near you. Point it at any location and get a curated list of nearby points of interest with Wikipedia summaries.

## Features

- Detects your current location or search any place
- Fetches nearby Wikipedia articles via GeoSearch API
- Clean map interface with clickable markers

## Stack

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

- Wikipedia GeoSearch API
- Leaflet.js maps
- Browser Geolocation API

## Getting Started

```bash
git clone https://github.com/sh00von/Locapedia
cd Locapedia
# open index.html in your browser
```
